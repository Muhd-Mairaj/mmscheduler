# MMScheduler

MMScheduler is an unofficial timetable planner for University of Malaya students. It helps you compare module occurrences, avoid clashes, and put together a class and exam schedule.

**[Try MMScheduler](https://mmscheduler.netlify.app/)**

> MMScheduler is a personal project and is not affiliated with Universiti Malaya. Timetable information may be incomplete or change, so always check your final schedule against official UM systems.

The latest data refresh targets **Semester 1, 2026/2027** (`2026/S1`). Some records may keep older period labels from the source data. The project has been used by UM students over the past four semesters.

## Features

- Single-screen planner: module list on the left, weekly timetable on the right (bottom-tab layout on phones)
- Search modules by code or name, or **paste a screenshot of your UM enrollment** and the modules and occurrences are added for you (OCR runs in your browser)
- Pick one occurrence per module; clashing occurrences are disabled and tell you what they clash with
- Weekly grid with overlap-aware layout, an alternative day-by-day list view, and an exam list
- **Auto-schedule**: preferred/avoided lecturers, days off, earliest start / latest finish, fewer campus days
- Credit totals, PNG export, light/dark themes, and your plan saved in local browser storage

- First-visit tour and a What's new panel (the ? button in the header)

### About auto-scheduling

Auto-scheduling is a local optimiser, not an LLM. It searches for the highest-scoring clash-free combination using branch-and-bound (so it stays fast even with modules that have 100+ occurrences) and runs in a Web Worker in your browser. Nothing is sent to an external service.

## Run locally

You need Node.js 20.9 or newer.

```bash
git clone https://github.com/Muhd-Mairaj/mmscheduler.git
cd mmscheduler
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). No environment variables or database are required.

For a production build:

```bash
npm run build
npm run start
```

## SEO and deployment

Metadata, `robots.txt`, `sitemap.xml`, a web manifest, Open Graph images and JSON-LD are generated by Next.js (`app/seo.js`, `app/layout.tsx`). Set `NEXT_PUBLIC_SITE_URL` to your production URL (default `https://mmscheduler.netlify.app`).

The OCR engine is self-hosted: `npm install` / `npm run dev` / `npm run build` copy it into `public/ocr` (git-ignored) via `scripts/copy-ocr-assets.mjs`, so no third-party CDN is used.

## Timetable data

The timetable data is bundled in `app/all_courses_updated_one_week_schedule_occ_separated.json`. The schedule data is refreshed regularly with course and occurrence details for Universiti Malaya.

## Built with

Next.js 16, React 19, CSS Modules, Lucide icons, and `html2canvas`. The app is deployed on Netlify and uses a bundled JSON dataset rather than querying TimeEdit directly.

## Project layout

- `app/Planner.js`: the single-page planner UI; `app/page.js` adds crawlable SEO content around it
- `app/hooks/`: `usePlanner` (plan state, persistence), plus small hooks for stored values, image paste/drop and media queries
- `app/lib/`: framework-free logic, unit-tested: `plan.mjs` (add/remove/select/import), `clash.mjs`, `solver.mjs` (+ worker), `enrollment.mjs` (OCR text parsing), `normalize.mjs`, `storage.mjs`, `time.mjs`
- `app/components/`: UI pieces (timetable, module list, dialogs, tour)
- `app/api/`: search and lookup over the bundled dataset (`app/lib/courses.js` loads it once)

Scripts: `npm run dev`, `npm run build`, `npm test` (unit tests), `npm run lint`.
